# Install this profile README

1. Log in to GitHub and create a **public** repository named **NDORRRRR**. The owner and repository name must exactly match your GitHub username. If GitHub offers **Add a README**, select it.
2. Upload the supplied `README.md` and the `assets/profile-banner.svg` file. Preserve the folder name and path. If you already created a README, replace its starter text with the supplied contents.
3. Visit your GitHub profile. GitHub should display the profile README above your pinned repositories.
4. The Top Languages and GitHub stats cards load from the third-party open-source GitHub Readme Stats service. They reflect available public repository data by default, not private code or ability. Cards may temporarily fail if the service is rate-limited.

If the public repository is created first, you can ask ChatGPT to push these changes on a separate branch and open a pull request for review, rather than editing main directly.
