# Setup

This is a **code-generated GIF**, not an AI-generated image. It works inside GitHub READMEs without JavaScript, CSS, external image services, or GitHub Actions.

1. In the public profile repository `NDORRRRR/NDORRRRR`, upload `assets/dev-terminal.gif` while keeping the folder path unchanged.
2. Replace the repository's root `README.md` with the supplied `README.md`.
3. Open the profile to check the animation. It loops automatically.

To edit the animated banner:

- Open `generate_banner.py`. Change `NAME_FIRST`, `NAME_LAST`, `ROLE`, `EDUCATION`, `SCENES`, or `COLORS` at the top.
- Install Python 3 and Pillow: `python -m pip install pillow`.
- Run `python generate_banner.py` from this folder.
- Commit the newly generated `assets/dev-terminal.gif` to the profile repository.

For the closest typographic match, use Inter and DejaVu Sans Mono system fonts. The distributed GIF already includes the intended appearance, so GitHub needs no fonts installed.

The file `assets/preview.png` is a still preview only, not needed in the repository. The README links JagaTani by name without exposing its private repository URL. The expandable languages table intentionally uses no third-party stats service, because the previous stats graphics failed to render.
